# Nayti 0.1.0-alpha.1

Первая распространяемая personal alpha Nayti — полностью локального поиска по фотографиям Android.

## Что доступно

- точный, нечёткий и смысловой поиск по распознанному тексту;
- поиск по визуальному содержимому фотографии;
- похожие изображения, копии и близкие кадры;
- фильтры по периоду, альбому и типу файла;
- выбираемый период подготовки с переиспользованием уже готового индекса;
- безопасные pause/resume, crash recovery незавершённой публикации и продолжение после остановки процесса;
- светлая, тёмная, системная и AMOLED-темы;
- полностью локальная работа без разрешения `INTERNET`, телеметрии и облачной обработки.

## Установка

1. Скачать `nayti-0.1.0-alpha.1-arm64.apk`, model pack и `SHA256SUMS` из одного GitHub Release.
2. Проверить контрольные суммы по инструкции из `INSTALL.md`.
3. Установить APK на ARM64-устройство с Android 11 или новее.
4. В приложении выбрать скачанный `.naytipack`, предоставить доступ к фотографиям и задать период первой подготовки.

Обновление поверх более ранней personal-alpha возможно только при совпадении сертификата. Локальные developer-сборки, подписанные Android Debug, требуют удаления перед переходом на публичный release certificate; это удаляет private index и model pack.

## Приватность release-процесса

Release не содержит примеров из личной медиатеки. В репозиторий, CI и release assets не входят фотографии, thumbnails, запросы, OCR, имена файлов, URI, MediaStore IDs, embeddings или необработанная диагностика с тестового телефона.

## Ограничения

Это ранняя ARM64 alpha с приоритетной проверкой на Samsung Galaxy S23+. Model pack импортируется вручную и занимает около 967 МиБ; первая подготовка большой медиатеки выполняется на CPU и может потребовать несколько сессий. Видео, лица, геопоиск, облачная синхронизация, аккаунты и редактирование оригиналов не поддерживаются.

Полный список находится в `KNOWN-LIMITATIONS.md` внутри bundle и в [known-limitations-alpha.md](../known-limitations-alpha.md).
