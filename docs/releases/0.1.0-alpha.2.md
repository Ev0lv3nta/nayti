# Nayti 0.1.0-alpha.2 — personal alpha

Персональная alpha для ручной установки. Проверки на Galaxy S23+ описаны в `evaluation/physical-2026-09-08.md` репозитория. Google Play не входит в этот этап. До публикации GitHub Release сборка остаётся кандидатом.

## Изменения

- Поиск выполняется вне UI-потока; отменённые запросы не подменяют свежие результаты.
- Результаты связаны с отправленным запросом; изменённые фильтры и способы поиска явно требуют нового запуска.
- При All идентификаторы и фразы в кавычках не запускают нейросети и не получают приблизительных дополнений; ручной выбор подмножества способов сохраняется. Интерфейс объясняет фактический маршрут.
- Причина невозможного старта подготовки объясняется отдельно от разрешения на уведомления.
- Viewer передаёт оригинал выбранному приложению; масштабирование ограничено фактическими границами изображения.
- Импорт моделей можно отменить. Действующий пакет остаётся доступным, пока кандидат проверяется.
- Для пакетов с известным размером требуемое место оценивается до чтения содержимого; неизвестный размер не блокирует безопасный импорт.
- Исправлен поиск по альбомам с отрицательным MediaStore ID; расширены тесты форматов и фильтров.
- Повторный импорт неизменного пакета сохраняет прежнюю запись, а не конфликтует из-за времени установки.
- Поисковая панель корректно располагается над клавиатурой; нижняя навигация скрывается во время ввода.

## Совместимость

APK: `versionCode=2`, `app.nayti`, прежний ключ подписи. Модели: неизменённый подписанный `nayti-offline-search-0.1.0-alpha.2.naytipack`, SHA-256 `2c90206b2c1ac09233a2b4f3c882dbe4e721bd52ddc3bde46cc6631d51a42167`.

Его manifest SHA-256 `1f87cfe37659bee690441e464ae66415c1623e8ae751320a9483adc6aff79d83` разрешён дополнительно **только для app versionCode 2**. Manifest и подпись пакета не изменяются. Это узкое решение для неизменённых моделей, preprocessing, runtime и engine API; не обещание совместимости будущих версий. Подпись, payload hashes, KAT, ABI и page-size policy сохраняются. Import и restore применяют одну policy.

Поскольку manifest/component/embedding identities не изменились, обновление APK само по себе не создаёт новый индекс и не требует повторного импорта. Новый неизвестный manifest не получает это исключение. App versionCode 3 потребует отдельного решения.

## Что ещё не подтверждено

Произвольные устройства/API, 16 KiB на физическом устройстве, универсальная точность и масштабирование на любую галерею. Проверенный корпус не устраняет ограничения visual negatives и pHash. Снимки личной галереи не используются в материалах выпуска.
